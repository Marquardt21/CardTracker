# Feature Specs

One file per feature area — durable reference for what a feature does, which files implement it, what's deliberately out of scope, and (where relevant) why non-obvious decisions were made. `Status: Planned` specs are written before implementation (via `/feature`); `Status: Implemented` ones are either updated after the fact or, for pre-existing features, written retroactively from the code.

Written by hand? no — generated and kept up to date by the `/feature` command (`~/.claude/commands/feature.md`), which writes one here after every confirmed spec and flips its status to `Implemented` once `feature-builder` finishes.
